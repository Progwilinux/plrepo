Hello, welcome to the Progwilinux software repository!

Unlike the old repository, the software here is delivered in a new package format – plpkg!

It's an archive containing the necessary files and directories, along with a ".PLPKG" file.
You can unzip and pack these archives manually using a zip utility, or a more convenient method – using plpkg utility!.

This package format (and utility) will be used in Progwilinux 26.5 and later.
